Data Inspection Questions

1. How many rows and columns are in the imported data?

The imported dataset contains 128 rows and 34 columns. Each row represents a survey observation, while each column represents a variable.

2. What are the variable names?

The questionnaire variables include q3 through q27, q30 through q34, q37, and q38. The dataset also includes OverallEmployeePerformace and employeeperformance.

3. Which variables look like questionnaire items, and which look like precomputed variables?

Variables beginning with “q” represent questionnaire items. OverallEmployeePerformace and employeeperformance appear to be precomputed variables measuring employee performance.

4. What is the difference between a variable label and a value label?

A variable label describes what a variable measures. A value label explains what individual response codes mean. For example, q38 measures whether a member lives in the headquarters area, while its value labels identify 1 as Yes and 2 as No.

5. Which variables contain missing values?

The missing-value analysis identifies q7, q8, and q37 as variables containing missing observations.

Create a Data Dictionary

A data dictionary documents the variables in the dataset, including their names, labels, data types, number of distinct values, and value labels. This helps identify coding inconsistencies and determine which variables require cleaning.

data_dictionary <- tibble(
  variable = names(data_raw),
  variable_label = map_chr(data_raw, \(x) attr(x, "label") %||% ""),
  class = map_chr(data_raw, \(x) class(x)[1]),
  n_distinct = map_int(data_raw, n_distinct),
  value_labels = map_chr(
    data_raw,
    \(x) {
      labs <- attr(x, "labels")
      if (is.null(labs)) "" else str_c(labs, "=", names(labs), collapse = "; ")
    }
  )
)

Data Dictionary Questions

1. Which variables have clear, useful labels?

Variables q3 through q6 have useful labels describing employee courtesy, helpfulness, professionalism, and availability. Variables q13 through q26 identify specific credit union services, while q27 indicates whether members currently have a loan.

2. Which labels should be revised for readability in your report?

The label for q8 should be revised because it incorrectly refers to statement frequency instead of members’ opinions about loan rates. The q38 label could be expanded to “Lives in Headquarters Area.” The two precomputed employee performance variables should also be clearly identified as existing calculated variables rather than original questionnaire responses.

3. Which variables are nominal, ordinal, or approximately interval? Explain at least three using the questionnaire.

  • Nominal: q38 measures whether members live in the headquarters area (Yes/No). These categories have no numerical ranking.
  • Ordinal: q13 measures awareness and use of regular share accounts, with three ordered categories ranging from awareness and use to being unaware.
  • Approximately interval: q3 through q6 measure employee proficiency using five-point agreement scales. For this assignment, these ratings may be treated as approximately interval when evaluating a multi-item index.

4. Which value labels are essential for interpreting the data, and which are predictable from the response scale?

Value labels are especially important for q13 through q26 because the numerical codes distinguish between using a service, knowing about it without using it, and being unaware of it. Labels for q7, q8, and q37 are also important because they include special responses such as “No Opinion.” Five-point agreement scales for q3 through q6 and q30 through q34 are more predictable, although documenting their endpoints remains necessary.

Fixing Metadata Problems

The original dataset contains incomplete value labels for several questionnaire items. Using the Case 31 questionnaire and coding instructions, the missing labels are added to a new dataset called data_labelled.

The two precomputed employee performance variables are excluded from this new dataset because they are not original survey questions. The original data_raw dataset remains unchanged.

# Five-point agreement scale
five_pt_likert <- c(
  "Strongly Disagree" = 1,
  "Disagree" = 2,
  "Uncertain" = 3,
  "Agree" = 4,
  "Strongly Agree" = 5
)

# Create a labelled copy without precomputed variables
data_labelled <- data_raw |>
  select(-c(OverallEmployeePerformace, employeeperformance)) |>
  mutate(
    across(
      c(q3:q6, q30:q34),
      \(x) set_value_labels(x, five_pt_likert)

Data-Quality Question

Does any variable contain a value that the questionnaire does not define?

Based on the observed values and the questionnaire’s coding instructions, the variables do not appear to contain values outside their defined response ranges. However, some variables contain missing responses, particularly q7, q8, and q37. Additional data preparation is necessary to ensure that special responses, such as “No Opinion” and “No answer,” are handled appropriately before statistical analysis.

Recode Special Responses and Reverse-Code Items

Some survey questions contain special response categories, such as “No Opinion” and “No Answer.” These responses should not be treated as numerical ratings because they do not represent an opinion on the measurement scale.

No Opinion and No Answer Responses

According to Case Exhibit 31.2, questions q7 and q8 use code 6 for “No Opinion,” while q37 uses code 6 for “No Answer.” These responses must be treated as missing values before further analysis.

data |>
  summarise(across(c(q7, q8, q37), \(x) sum(x == 6, na.rm = TRUE)))

data <- data |>
  mutate(across(c(q7, q8, q37), \(x) na_if(x, 6)))

The special response categories were checked and recoded to missing values where applicable. This prevents responses such as “No Opinion” from being incorrectly included in calculations of means, correlations, or other statistical analyses.

Reverse Coding

Reverse coding changes the direction of a numerical scale so that higher values represent more favorable responses.

According to the Case 31 questionnaire, q7, q8, and q37 use five-point scales, while q10 uses a four-point scale. These items need to be reversed so that higher values represent more favorable evaluations.

The reverse-coding formula is:

Reversed value = Minimum + Maximum - Original value

data <- data |>
  mutate(
    q7r = 6 - q7,
    q8r = 6 - q8,
    q10r = 5 - q10,
    q37r = 6 - q37
  ) |>

Reverse-Coding Questions

1. Why is a reversal inappropriate for q9? How could you code q9 to answer “was the frequency about right?” instead?

Reverse coding is inappropriate for q9 because the response scale measures how frequently members receive financial statements, and the most favorable response is “About Right,” which is in the middle of the scale. Reversing the numbers would not correctly represent satisfaction.

A better approach would be to create a binary variable where 1 means the frequency was “About Right” and 0 means the frequency was either too frequent or not frequent enough.

2. Why should q13 to q26 not be reversed or averaged into one score? What would be a more appropriate way to summarize them?

Questions q13 through q26 measure members’ awareness and use of different credit union services. These responses are categories rather than a traditional satisfaction rating scale. Averaging them would combine different services into a number that may not have a clear interpretation.

A better approach would be to calculate frequencies and percentages for each awareness category and service. This would help identify which services members use, know about, or are unaware of.
